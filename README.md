# 4-1-2 动手实验：算法分类与建模基础

> AI 大模型课程 4-1-2 的一晚实验项目：不用背定义，亲手把四个分类器、四个回归器跑一遍，
> 亲眼看到训练集/测试集长什么样、过拟合长什么样，概念就长在手上了。

GitHub 仓库：https://github.com/awe0bit/ml-412-lab

## 四个脚本分别对应哪个概念

| 脚本 | 对应的 4-1-2 概念 | 一句话讲清 |
|---|---|---|
| `01_分类实验.py` | 分类问题 | 给数据贴标签：良性/恶性二选一，对比 4 个分类器的测试集准确率 |
| `02_回归实验.py` | 回归问题 | 预测连续数值：病情进展分数，对比 4 个回归器的 R² / RMSE |
| `03_划分可视化.py` | 训练集 / 测试集划分 | PCA 把 20 维压成 2 维画出来：测试集是混在训练集里的"没见过的新数据"，不是偏到角落的特殊数据 |
| `04_过拟合可视化.py` | 过拟合 | 决策树深度 1→15：训练准确率一路涨到 1.0，测试准确率先涨后跌，跌下去那段就是过拟合 |

## 数据：现场随机生成，不用现成数据集

四个脚本每次运行时都现场造数据（脚本顶部 `SEED = None`，每次运行都重新随机）：

- **分类用**：`make_classification` 生成 20000 个样本、20 个特征
  （12 个有效特征 + 4 个冗余特征），二分类，带 2% 标签噪声
- **回归用**：`make_regression` 生成 20000 个样本、15 个特征
  （10 个有效特征），目标是带噪声的连续数值

想复现某次结果：把脚本顶部的 `SEED = None` 改成任意整数即可。
每次运行数据都不同，对比表的具体数字会有波动——看的是"谁强谁弱"的相对关系，
不是死记数字。数字变了但规律不变，这本身就是一课。

## 运行方法

```bash
pip install -r requirements.txt

python 01_分类实验.py   # 分类算法对比
python 02_回归实验.py   # 回归算法对比
python 03_划分可视化.py # 生成 images/03_train_test_split.png
python 04_过拟合可视化.py # 生成 images/04_overfitting_curve.png
```

四张表/两张图跑完约 1 分钟。图片用无界面（Agg）后端直接存文件，服务器上也能跑。

## 预期输出（每次随机生成，数字会波动，看相对关系）

**分类（测试集准确率）**：随机森林和 K近邻通常最强（0.95+），
决策树训练集 1.0 但测试集明显更低（死记硬背），
逻辑回归在这份数据上偏弱——因为生成的数据类别是多团块分布，
一条直线切不开，K近邻这种"看邻居"的反而对路。

**回归（测试集）**：线性回归和 Ridge 的 R² 通常 0.98+（数据本来就是线性生成的），
随机森林其次，单棵决策树回归明显最差。

**过拟合曲线**：深度=10 左右测试准确率最高；再往深，
训练准确率继续往 1.0 爬，测试准确率掉头向下——这就是过拟合拐点。

## 三个概念的一句话直觉版

- **分类 vs 回归**：输出是离散标签就是分类（猫/狗、良/恶性），输出是连续数字就是回归（房价、病情分数）。
- **训练集 / 测试集**：训练集是课后习题，测试集是期末考卷——必须用没见过的数据考，分数才作数。标准化、分层这些操作都只能拿训练集的信息做，否则就是"偷看考卷"（数据泄露）。
- **过拟合**：模型把训练集的噪声也背下来了——习题全对，考试翻车。治法：简化模型（限制树深）、正则化（Ridge）、或用随机森林这种"三个臭皮匠"。
